# Simple Calculator 🧮

A simple calculator built using HTML, CSS, and JavaScript.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear Button
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start calculating!
